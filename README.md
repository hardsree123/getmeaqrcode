# GetMeAQRCode — AI-Powered QR Code SaaS Generator

A modern, high-performance, and feature-rich QR Code SaaS Generator built with **pure web technologies (HTML5, CSS3, JavaScript ES6+, HTML5 Canvas, and Vector SVG)** with zero external dependencies and zero build steps.

**Live URL**: [https://getmeaqrcode.vercel.app](https://getmeaqrcode.vercel.app)  
**Official Domain**: [https://getmeaqrcode.com](https://getmeaqrcode.com)

Benchmarked against [QRCodeCreator.com](https://qrcodecreator.com/) and QRCode Monkey, with an added **AI Art Generation Studio** and **SaaS Analytics Engine**.

## 🌟 Key Features

### 1. 20+ QR Code Data Types & Payloads
- **Website URL**: Standard HTTP/HTTPS with optional UTM Campaign Parameter generator.
- **vCard 3.0**: Digital Business Card (Name, title, company, phone, email, website).
- **Wi-Fi Network**: Scan-to-connect (WPA/WPA2/WPA3, WEP, Open, Hidden SSID).
- **Social Media**: Link-in-Bio multi-link profile aggregator.
- **Plain Text**: Up to 500 characters of notes, instructions, or codes.
- **Email**: Pre-filled `mailto:` with subject line and body template.
- **SMS & Phone**: Encoded `smsto:` and `tel:` direct dialing.
- **WhatsApp**: Direct chat links (`https://wa.me/...`).
- **PDF Hosting**: Responsive document viewer link generator.
- **App Store**: Unified redirection link for iOS App Store & Android Google Play.
- **Restaurant Menu**: Table-specific digital menu link generator.
- **Cryptocurrency**: Bitcoin, Ethereum, Solana, and USDT payment requests.
- **Calendar Event (iCal)**: Event summary, dates, venue, and auto-add to calendar.
- **Geo-Location**: Coordinates linking to Google Maps.
- **Rating & Reviews**: Direct links to Google Reviews or Trustpilot.

## 🚀 How to Run

Because this project is built on **pure web standards without node_modules or build steps**, you can run it immediately:

### Option 1: Direct Browser Launch
Simply double-click or open `index.html` in any modern web browser (Google Chrome, Edge, Safari, Firefox).

### Option 2: Local HTTP Server (Optional)
If you have Python or Node installed, you can serve it locally:

```bash
# Python 3
python -m http.server 3000

# or with npx
npx serve .
```
Then visit `http://localhost:3000`.
